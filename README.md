BOOKIFY – Digital Library Platform

Project Description

BOOKIFY is a digital library platform developed using React.js. It helps users discover books, explore different authors, and manage their personal reading library in one place.

The platform provides a simple and user-friendly experience for readers.

Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- React Router
- Git and GitHub

Main Features

- Browse and discover books.
- Search for books by title, author, or category.
- Filter books by category and rating.
- View detailed information about each book.
- Borrow available books.
- Add and remove books from the wishlist.
- Manage borrowed books in My Library.
- Track reading progress and reading goals.
- Rate and review books.

Website Pages

1. Home Page

Introduces BOOKIFY and displays featured books and the platform's main features.

2. Explore Books

Allows users to browse the book collection, search for books, and use filters.

3. Book Details

Displays information about a selected book, including its title, author, rating, description, and availability.

4. My Library

Allows users to manage their borrowed books, wishlist, and reading activity.

5. Login and Sign Up

Provides user interface pages for logging in and creating an account.

Installation and Setup

Follow these steps to run the project locally.

1. Clone the repository

git clone https://github.com/72330009-coder/BOOKIFY.git

2. Open the project folder

cd BOOKIFY

3. Install dependencies

npm install

4. Start the development server

npm start

5. Open the website

Open your browser and visit:

http://localhost:3000
